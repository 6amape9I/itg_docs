5. Жёсткое правило для N3-ready по score
5.1 Проблема

В N2.1 часть групп с низким group_score всё ещё попадает в n3_candidate_groups.csv, потому что есть clean reason вроде:

high_sequence_similarity_without_scope_conflict
known_safe_abbreviation_match
shared_latin_candidate_non_short

Это слишком мягко.

5.2 Новое правило

Группа может быть n3_ready=true, только если выполняется одно из условий:

Условие A. Нормальный score
group_score >= 0.72

и есть хотя бы один clean reason.

Условие B. Hard alias exception
group_score < 0.72

допускается только если есть hard alias reason.

Hard alias reasons:

primary_label_exact_match
explicit_parenthetical_alias_match
explicit_alias_exact_match
product_variant_match
canonical_alias_exact_match

Но даже hard alias exception запрещён, если есть subtype/location/scope conflict.

5.3 Не считать hard alias exception

Не считать достаточной причиной для score exception:

high_sequence_similarity_without_scope_conflict
known_safe_abbreviation_match
shared_latin_candidate_non_short
high_token_similarity
moderate_sequence_similarity
same_document_cooccurrence

Эти причины могут поддерживать score, но не должны сами по себе протаскивать группу с group_score < 0.72.

5.4 Новый exclusion reason

Если группа не проходит по score:

score_below_n3_threshold_without_hard_alias_reason
